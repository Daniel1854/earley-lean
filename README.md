## ToDo
- understand Earley Recognizing
  - top down, no backtracking, no need for lookahead
  - at each input we have a _set_ of possible states
      - Earley G w refers to this inductively defined state set
  - 3 operations:
    - Prediction: add all the rules which could happen to the state space through application of rules w/o extra input
    - Scanning: add all the rules w/ next input
    - Completion: for every state that is at the end of its rule, go back to the state set of the beginning input&search unfinished derivations
      and add each one of those to the current state
  - Earley Items: each S(n) is a Set { (A -> α . β, j)}, where j refers to the initial state set the derivation began
  - accepts if (X → γ •, 0) ends up in S(n), where (X → γ) is the top level-rule and n the input length
  - question: how do these operations get queued up? we are finished when there is nothing more to do
    - we go from the initial stateset 0 to the final stateset n and loop through all the states at that input length
    - depending on the type of the next input it is deterministic which of the 3 ops we want to do
  - basicly you keep track of the closure of all the state we could be in right now, and if we are in a finished state at the end, then we accept
  - this seems to be the easy part
